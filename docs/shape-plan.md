# Shape plan: CEO dashboard (Impeccable `shape`)

Mode: **Operate** (a reading task under time pressure). Ambition shows as precision and restraint.

1. **Job and audience:** a CEO on a phone between meetings needs to know, in five seconds, which resort needs help, what it costs and who acts.
2. **Outcome and proof:** a one-line live verdict under the title ("Ubud needs the most help…") answers the 10-second test before any scrolling. The ranked issue list proves it with money at stake and an owner.
3. **Direction:** annual-report calm. White page, one sans family, large tabular numerals, hairline rules instead of card boxes. Black is reserved for problems, so the eye lands on black first: black status marks, black issue markers, black pins, black scorecard cells, black OTA and "behind" bars.
4. **Sequence:** header + verdict → filter bar (sticky on tablet/desktop) → reading key → KPIs (RevPAR hero full width, five tiles below) → issues (largest heading, thick black top rule, biggest type after the hero) → map (two panels + worst-first list) → scorecard → four charts → footer.
5. **Interaction:** tapping an issue, pin or scorecard row focuses the page on that resort; a focus banner offers "Back to all resorts". Charts take pointer and arrow keys; each has "View as table".
6. **Responsive:** single column under 768px, tiles 2-up, map panels stacked, scorecard scrolls sideways with names pinned. Map labels are HTML overlays at fixed px size; secondary labels hide automatically if they collide.
7. **States:** last-year compare excludes Ubud (said in words); focused on Ubud with last year falls back to the ramp-up plan and says so; resorts with no issues show "No issues in this period".
